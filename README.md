# Rayawa

English | [简体中文](README_zh.md)

A repository index and archive of Minecraft-related public resources and starter examples.

## Overview

The default README serves as a project index. The `mc-pubFiles/` archive contains starter source examples, version resources and retained game materials. This repository has no unified application or build pipeline; the landing page contains project information only.

## Technology and Dependencies

Markdown for the index. The starter examples are C++ source files; their build/runtime requirements must be checked independently. Archived game resources require the corresponding game version.

## Repository Structure

- `README.md` — project index
- `mc-pubFiles/` — Minecraft-related archive
- `mc-pubFiles/versions/` — versioned resources
- `LICENSE` — repository license text

## Quick Start

Browse the index and archive in GitHub or a Markdown viewer. Read the subdirectory notes before using version-specific materials. For current application and embedded projects, consult the corresponding project repositories. No repository-wide install or start command is provided.
