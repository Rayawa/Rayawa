# Rayawa

[English](README.md) | 简体中文

包含 Minecraft 相关公开资源与启动器示例的仓库索引和归档。

## 项目概述

默认 README 用于项目索引。`mc-pubFiles/` 保存启动器源码示例、版本资源与游戏资料。本仓库没有统一应用或构建流水线，首页仅保留项目信息。

## 技术栈与依赖

索引使用 Markdown；启动器示例为 C++ 源文件，需分别核对构建和运行条件。归档游戏资源需要对应游戏版本。

## 文件结构

- `README.md` — 项目索引
- `mc-pubFiles/` — Minecraft 相关归档
- `mc-pubFiles/versions/` — 版本资源
- `LICENSE` — 仓库许可文本

## 快速上手

在 GitHub 或 Markdown 阅读器中浏览索引与归档，使用特定版本资料前先阅读子目录说明。当前应用和嵌入式项目以对应项目仓库为准，本仓库没有统一安装或启动命令。
